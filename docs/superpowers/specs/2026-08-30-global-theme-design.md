# SmartComp 全局明暗主题设计

## 背景

当前应用固定使用 Ant Design 浅色算法和一套浅色 CSS 变量，但工作流画布在组件内部维护第二套局部主题。局部深色状态只改变画布变量，工具栏仍保留浅色背景；按钮又从画布继承浅色文字，造成“浅色画布”和“重置”看似消失。移动端还会按设计隐藏两段按钮文字，仅显示图标。

本次不继续修补局部画布主题，而是将主题所有权上移到应用根节点，让所有普通页面和组件使用同一个明暗状态。

## 目标

- 在全局顶栏提供浅色/深色切换，所有路由保持一致。
- Ant Design 组件与自定义 CSS 同步切换，避免弹窗、按钮、卡片出现混合主题。
- 首次访问跟随系统偏好；用户手动切换后在浏览器中记住选择。
- 工作流画布移除独立主题状态和入口，直接跟随全局主题。
- 深色主题保持简约清晰，以蓝黑背景、分层表面、蓝色和薄荷绿状态色为主，不使用纯黑大面积铺底。
- 桌面端和移动端都保留明确、可访问的主题切换入口。

## 非目标

- 不增加“自动/浅色/深色”三态设置页。
- 不修改后端、数据库、用户权限或 API。
- 不重写 StrategyAgent 生成的独立 HTML 报告；报告页外壳跟随主题，iframe 内的可导出报告维持原始样式。
- 不借主题改造重排页面信息架构或重做业务组件。

## 主题架构

### 单一状态源

`App.jsx` 持有唯一的 `appTheme`，值只允许 `light` 或 `dark`。初始化顺序：

1. 读取本地存储中的有效用户选择。
2. 没有有效选择时读取 `prefers-color-scheme: dark`。
3. 无法访问浏览器能力时回退到 `light`。

主题变化时同时：

- 写入 `document.documentElement.dataset.theme`；
- 设置浏览器 `color-scheme`；
- 持久化用户选择；
- 切换 Ant Design 的 `defaultAlgorithm` / `darkAlgorithm`。

主题初始化、校验和持久化逻辑提取为纯工具函数，避免组件中散落浏览器判断，并便于单元测试。

### CSS 令牌

现有 `--sc-*` 变量继续作为全站语义令牌。浅色值保持现状，`html[data-theme='dark']` 覆盖背景、表面、正文、弱化文字、边框、阴影和控件背景。

新增或整理以下语义层，而不是在组件中继续增加孤立的十六进制颜色：

- 页面背景与柔和背景；
- 默认、柔和和悬浮表面；
- 主文字、次文字和反色文字；
- 默认与强调边框；
- 控件、代码区和遮罩背景；
- 主题相关阴影。

品牌蓝、薄荷绿、警告色和错误色保持语义，但深色环境允许提高亮度与对比度。

### 工作流画布

`PipelineGraph` 删除局部 `theme` state、`data-theme` 和画布主题按钮。画布变量由全局主题选择器覆盖，缩放、重置、阶段导航和移动端布局保持不变。

这会直接消除当前按钮文字与画布主题分离的问题：工具栏、按钮、画布和详情区均从同一个全局主题读取颜色。

## 交互设计

- 切换入口放在顶栏运行状态右侧，属于应用级控制。
- 桌面端显示图标和“深色模式”或“浅色模式”；移动端只显示图标，但保留动态 `aria-label` 和 `title`。
- 控件使用按钮的按下态表达当前是否为深色模式。
- 切换即时生效，不刷新页面，也不改变当前路由、任务状态、画布位置或报告视图。
- 主题色变化使用短暂的颜色过渡；当用户启用减少动态效果时取消过渡。

## 页面范围

验收覆盖：

- 分析中心首页和任务创建区；
- 任务详情、Agent 工作流、活动记录和详情抽屉；
- 报告概览、JSON 视图、加载态和空态；
- 顶栏、运行配置状态、Ant Design 按钮、弹层和提示。

完整 HTML 报告 iframe 是独立交付物，只调整其外层容器、加载态和边界，不向 iframe 注入主题 CSS。

## 错误处理与兼容

- 本地存储读取或写入失败时，主题仍在当前会话中正常切换。
- 无 `matchMedia` 的环境回退到浅色。
- 只接受 `light` / `dark`，忽略损坏或未知的存储值。
- 主题按钮保持键盘操作、可见焦点和屏幕阅读器语义。

## 验证策略

- 纯函数测试：存储优先级、系统偏好回退、非法值回退、切换结果。
- 组件静态检查：全局主题按钮文案和 `aria-pressed` 随状态变化；画布不再提供局部主题入口。
- 现有前端全量测试、ESLint、生产构建和 `git diff --check`。
- 真实浏览器视觉检查：桌面与 360/430px 移动端分别检查首页、任务工作台和报告页的明暗主题；确认按钮文字可见、无全局横向溢出、状态色与正文对比清楚。
- 不运行真实 LLM、联网分析或后端全量流水线，因为本次只改变前端主题表现。
